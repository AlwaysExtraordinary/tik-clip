# 使用教程

## 1. 安装

```bash
git clone
npm i
npm run dev
```

## 2. 使用

启动项目后在浏览器打开，点击设置，选择文件夹并授予权限，即可在视频页面看到已有视频。<br>
**注意，每个视频需要单独文件夹存放，否则无法识别** ，同目录下可以存放图片，默认识别为封面。
